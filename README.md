# 一本小本子 · 留存网站

把高三那本记小事的小本子，做成一个可以一直看、一直存的网站。

纯静态：没有服务器、没有数据库、没有第三方依赖。整个文件夹拷到任何地方，双击 `index.html` 就能打开，断网也行。

---

## 现在就能看

双击 `index.html`。

- 首页是全部页面，点一张卡片翻开
- 搜索框可以搜文字内容（按 `/` 键快速聚焦）
- 标签、以及「待转录」可以筛选
- 阅读器里 `←` `→` 翻页，`Esc` 关闭，点图片可以看原图
- 「打印 / 存成 PDF」能把整本做成纸质小册子或 PDF

现在网站里是 **36 页照片**（`photos/001.jpg`–`036.jpg`，001 是封面、036 是后记），文字还没开始抄——没抄的页会显示「待转录」，不影响看图。抄字见下一节。

---

## 在手机上看（同一个 WiFi）

双击 **`启动网站.bat`**，会打开一个黑色窗口，里面写着两个地址：

- 这台电脑：`http://127.0.0.1:8000`
- 同一 WiFi 的手机：`http://你电脑的局域网 IP:8000`

窗口别关，关掉网站就停了。第一次运行时 Windows 可能弹防火墙提示，点「允许访问」。

只是自己看的话，双击 `index.html` 就够了，不需要它。

## 目录结构

```
启动网站.bat              双击 = 在这台电脑/同一 WiFi 里提供一个网址
index.html                页面骨架（标题、开场白在这里改）
assets/css/style.css      样式
assets/js/app.js          翻页、搜索、筛选的逻辑
data/pages.js             页面清单：哪张图对应第几页
data/notebook.js          文字内容 ← 你主要编辑这个
images/pages/             本子的图片（网页用的大图）
images/thumbs/            阅读器用的小图（脚本自动生成，520px）
images/grid/              首页照片墙用的更小的图（脚本自动生成，360px）
images/placeholder.svg    图片缺失时的占位图
转录.html                 转录工具：看照片、敲文字、导出 notebook.js
tools/import-pages.ps1    批量导入照片
tools/make-grid-thumbs.py 生成首页照片墙的小图（导入后跑一次）
photos/                   照片先丢这里
README.md                 本文件
```

## 把自己的一页一页加进去

### A. 先手动试两页（推荐）

1. 把照片放进 `images/pages/`，比如 `page-001.jpg`
2. 打开 `data/pages.js`，加一行：`{ page: 1, image: "images/pages/page-001.jpg" }`（`thumb` 可以省，会自动用大图）
3. 打开 `data/notebook.js`，照现成的样子加一条，把字抄进去
4. 刷新网页

### B. 页数多，用脚本批量导入

1. 把照片全部拷进 `photos/`（按页码顺序命名：`001.jpg`、`002.jpg`……）
2. 在网站根目录运行：

   ```powershell
   powershell -ExecutionPolicy Bypass -File tools\import-pages.ps1
   ```

   > **方向不对怎么办**：脚本默认认为照片本身已经是正的（手机导出的图通常如此）。如果导入后有个别页横过来了，用页码指定顺时针转 90° 再导一次：
   >
   > ```powershell
   > powershell -ExecutionPolicy Bypass -File tools\import-pages.ps1 -RotatePages "1,36"
   > ```
   >
   > 只有相机的 EXIF 方向可信时，才加 `-ExifRotate`。

   也可以右键 `tools/import-pages.ps1` → 使用 PowerShell 运行。若提示脚本被禁止，就右键文件 → 属性 → 解除锁定，或按上面的命令加 `-ExecutionPolicy Bypass`。

3. 脚本会把照片缩到长边 1800px（够清晰，又不至于几百 MB），生成 `images/pages/page-001.jpg`……；同时生成一张 520px 的小图放进 `images/thumbs/`；最后重写 `data/pages.js`
4. 再跑一次下面的命令，生成首页照片墙专用的 360px 小图（每张约 20KB）：

   ```powershell
   python tools\make-grid-thumbs.py
   ```

5. 然后只需要在 `data/notebook.js` 里一页页补文字

脚本**只重写 `data/pages.js`，不会动 `data/notebook.js`**，所以已经抄好的文字不会丢。可以放心反复运行。

> 原图另外存一份（硬盘 + 云盘）。网页里的是「方便看的版本」，原图才是母版。

### 手机照片怎么进电脑

**iPhone（数据线最快，也不压缩）**

1. iPhone **设置 → 照片 → 传输到 Mac 或 PC → 选「自动」**
   （这样导出来是 JPG；选「保留原片」会是 HEIC，Windows 默认打不开，脚本也处理不了）
2. 数据线连电脑，手机上点「信任」，输入锁屏密码
3. 打开「此电脑」，会出现 **Apple iPhone**，进去 `Internal Storage → DCIM → 100APPLE`，把照片复制到 `photos/`
4. 也可以用 Windows 自带的「照片」应用：**导入 → 从 USB 设备** → 选照片 → 导入

**安卓**

1. 数据线连电脑，手机下拉通知栏，把 USB 用途改成「**传输文件 / MTP**」
2. 「此电脑」里出现手机后，进去找 `DCIM → Camera`，复制到 `photos/`
3. 华为 / 小米 / OPPO / vivo 也可以用自己的手机助手（华为手机助手、小米互传等）导出

**没有数据线**

- 网盘 App 自动备份（百度网盘 / 阿里云盘 / 夸克），电脑端下载
- iPhone 用 iCloud：电脑登录 icloud.com，或装 iCloud 客户端下载
- 微信「文件传输助手」、QQ「我的电脑」也能传，但**会压缩**，字容易糊，只当应急

> 传完检查一下：`photos/` 里应该是 `.jpg`（不是 `.heic`），数量对得上。再把文件名改成 `001.jpg`、`002.jpg`……顺序就是页码。

### 用「转录工具」一页页敲（推荐）

双击运行网站（`启动网站.bat`），浏览器打开 **`转录.html`**，或者直接双击它：

1. 左边是本子照片，右边填**小标题 / 日期 / 地点 / 正文 / 注释 / 标签**
2. 敲完一页，点「下一页」（或 `Ctrl + Enter`），草稿自动存在浏览器里
3. 写一部分也没关系，点右上角 **「导出 notebook.js」** 下载文件
4. 用下载的 `notebook.js` 覆盖 `data/notebook.js`，刷新网站就看到文字了

> 草稿只存在这个浏览器里：换电脑、清缓存、换浏览器都会丢，所以**写完记得导出**。
> 网页底部那排小方块是 36 页的进度，红色表示已经写过。

### 文字怎么抄

- 按本子上的原样抄。错别字、涂改、脏话、缩写都别改——那才是当时的你。
- `note` 里写现在的你才懂的事：这人是谁、那天为什么好笑、后来怎么样了。**这部分十年后会变得最值钱。**
- 一页大概五分钟。一天两页，一个月就抄完了。

## 数据字段

`data/pages.js`

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `page` | 是 | 页码，数字，用于排序和对应文字 |
| `image` | 是 | 图片路径，相对网站根目录 |
| `thumb` | 否 | 缩略图路径，不写就用 `image` |

`data/notebook.js`

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `page` | 是 | 要和 `pages.js` 里的页码一致 |
| `title` | 否 | 小标题，一两个词 |
| `date` | 否 | 写成 `2026-06-14`，显示成 2026.06.14 |
| `place` | 否 | 当时在哪儿 |
| `text` | 否 | 正文；换行会原样保留 |
| `note` | 否 | 现在补的注释 |
| `tags` | 否 | `["晚自习", "停电"]`，用来筛选 |

同一页只有图、或只有字，都能正常显示；两边都没有的页码不会出现。

`data/notebook.js` 顶部还有一行 `window.NOTEBOOK_YEAR = "2026";`——在所有页都还没写日期的时候，首页「年份跨度」就显示这个；等抄了几页带 `date` 的，会自动显示真实年份范围。

## 放上网（可选）

纯静态网站，任何静态托管都能放。

**GitHub Pages（免费、最省事）**

1. 注册 GitHub，新建仓库，比如 `notebook`，选 **Public**
2. 把这个文件夹里的所有文件传上去（网页上拖拽也行）
3. 仓库 **Settings → Pages**，Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`
4. 等一两分钟，访问 `https://你的用户名.github.io/notebook`

**Cloudflare Pages / Vercel / Netlify**：注册后直接把这个文件夹拖上去上传，免费，不用 Git。

**国内对象存储**（阿里云 OSS、腾讯云 COS）：上传成静态网站，费用很低；想用自定义域名需要备案，默认域名访问网页有时会被强制下载。

> 上线后如果不想被搜索引擎收录，在根目录加一个 `robots.txt`，两行：
>
> ```
> User-agent: *
> Disallow: /
> ```
>
> 但这只是「请别收录」，不是密码保护。

## 打开有点慢？

首页现在做了三层减负：

1. **首屏只铺 12 页**，下面的点「再看 12 页」再加载 —— 慢网络下不会一次性请求几十张图
2. **照片墙用 360px 小图**（每张约 20KB），而不是 520px（约 50KB）
3. **点开阅读器才加载大图**（每页约 500KB），还会自动预取前后页；某张图万一请求失败，会自动换小图、再不行才显示占位图，不会留白块

如果还是慢，多半是网络到 GitHub 的问题——`github.io` 在国内经常很慢。

**手机上的额外优化（已内置）**：窄屏时阅读器只下载 520px 的小图（约 50KB），不下载 1800px 大图；顶部工具栏的毛玻璃、卡片的小倾斜在手机上会自动关掉，滚动更跟手。

**办法 1：图片走 jsDelivr（只改一行）**

打开 `data/notebook.js`，把这一行填上：

```js
window.NOTEBOOK_CDN = "https://cdn.jsdelivr.net/gh/你的用户名/仓库名@main/";
```

注意最后要带斜杠。图片改由 jsDelivr 送，国内一般快很多；文字和照片仍然在你自己仓库里。

**办法 2：图片再压小一点**

```powershell
powershell -ExecutionPolicy Bypass -File tools\import-pages.ps1 -RotatePages "1,36" -MaxWidth 1400 -Quality 78
```

**办法 3：换个托管**

Cloudflare Pages 通常比 GitHub Pages 在国内稳一些；最稳的仍是备案过的国内对象存储/服务器。

**怎么确认是谁慢**：网页里按 `F12` → Network，刷新，看耗时最长的是哪个文件。是 `page-*.jpg` 就压缩或换 CDN；是 `index.html` 本身慢，那就是网络到托管平台的问题。

## 隐私

本子里大概率有同学的真名、外号和私事。

- 公开托管 = 谁都能看。要么用化名/缩写，要么先打码
- 真想私密：GitHub 私有仓库 + Cloudflare Access；或者干脆只在自己电脑和 U 盘上看（双击 `index.html` 完全够用）
- 别把密码、住址、身份证号这类东西放进公开页面

## 长期保存：网站只是「阅读界面」

真正要活下来的，是 `images/` 和 `data/` 这些文件。

1. **3-2-1**：3 份副本、2 种介质、1 份异地。电脑 + 移动硬盘 + 云盘（两家更稳）
2. **每年体检一次**：打开网站、随机抽 3 页点开原图、确认云盘能下载。打不开的备份不算备份
3. **用 Git 管版本**：每次加页 commit 一次，以后改错字也能翻回去
4. **原件别丢**：纸本子平放、避光、防潮，不要塑封
5. **做一份 PDF**：点「打印 / 存成 PDF」，和照片一起进备份；纸和 PDF 都不依赖任何网站
6. **介质会坏**：U 盘、硬盘五到十年就该换新，别把宝押在一块旧盘上

## 常见问题

**照片太大 / 网页卡**
手机原图一张 3–5 MB，一百页就是几百 MB。用上面的脚本缩到长边 1800px，单页通常 200–500 KB。GitHub 仓库建议控制在 1 GB 以内。

**别用微信传图**
微信会压缩，字会糊。用数据线、QQ「原图」、AirDrop 或网盘。

**iPhone 的 HEIC 照片**
Windows 上一般打不开。手机「设置 → 相机 → 格式」选「兼容性最佳」，或导出时转成 JPG。脚本只处理 jpg/png/webp。

**页码乱了**
文件名排序决定顺序。拍照时按顺序拍，导入前检查文件名编号。

**想改标题、年份、自我介绍**
在 `index.html` 顶部的 `.hero` 区块里改文字。

**想加封面**
把封面照片放进 `images/pages/cover.jpg`，在 `pages.js` 里加 `{ page: 0, image: "images/pages/cover.jpg" }`，文字写在 `notebook.js` 里 `page: 0` 那一条。

**以后想放第二本本子**
复制整个文件夹改名、分别部署。想合并进同一个网站，就让页码错开（第二本从 1001 开始）。

## 技术说明

- 无框架、无构建、无 CDN、无外部字体，所有资源都在本地
- 数据用 `window.NOTEBOOK_*` 全局变量而不是 `fetch`，所以 `file://` 双击直接能跑
- 深链接：`index.html#page-3` 可以直接打开第 3 页
- 打印样式在 `style.css` 最后，想做纸质小册子就改那里
- 手机端会自动变成单列；图片懒加载
